# qbox
> Приложения в контейнерах podman

## Задачи утилиты

1. Устанавливать deb/rpm пакеты на любых дистрибутивах.
2. Не создавать проблемы с зависимостями и средой.
3. Запускать приложение в контейнере.

## Зависимости

- podman и distrobox
- python >3.12

## Использование

1. Скачайте исходники или релизную версию (рекомендуется)

- Из Git репозитория:
```
git clone https://github.com/b-e-n-z1342/qbox.git
cd qbox
chmod +x install_qbox && ./install_qbox
```
- Релизная сборка
```
tar -xf qbox.tar.xz
cd qbox && chmod +x INSTALL && ./INSTALL
```
!! Осторожно: релизная версия для установки может потребовать zenity
